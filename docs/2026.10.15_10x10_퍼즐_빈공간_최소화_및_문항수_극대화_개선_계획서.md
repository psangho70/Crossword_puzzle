## 1. 개선 배경 및 목적

### 1.1 현상 분석 (사용자 제기 문제)
- **과도한 빈 공간**: 10x10 격자(총 100칸) 도입 후, 현재 각 단계별 문항 수가 12~13개, 활성 칸 수가 28~32칸(평균 28.7칸)에 불과함.
- **공간 쏠림 현상**: 예시(스테이지 1 - 2단계)와 같이 특정 영역(우상단)에만 단어가 뭉쳐 있고, 좌측 4개 열(0~3열)과 하단 3개 행(7~9행)이 완전히 비어 약 70%가 회색 미사용 빈칸으로 방치됨.
- **사용자 요구**: "10X10 퍼즐인데 사용하지 않는 공간이 너무 많습니다. 빈 공간이 없도록 단계별 문항수를 늘려서 최대한 많은 문항을 담을 수 있도록 개선이 필요합니다."

### 1.2 목표치 설정
1. **단계당 문항 수 대폭 확대**:
   - 기존: 12 ~ 13문항
   - **목표: 18 ~ 22문항 (약 60%~75% 대폭 증가)**
2. **격자판 활성 칸(Filled Cells) 밀도 극대화**:
   - 기존: 28 ~ 32칸 (평균 28.7칸, 28% 활용)
   - **목표: 48 ~ 58칸 (평균 50칸 이상, 50% 이상 활용, 약 1.8배 향상)**
3. **격자판 전역 커버리지(Grid Coverage) 보장**:
   - 단어가 한 구석에 쏠리지 않고, 10x10 전체 영역(상하좌우 및 모서리 근처까지) 골고루 배치.
   - 바운딩 박스 제약: `minR <= 1`, `maxR >= 8`, `minC <= 1`, `maxC >= 8` 충족.
4. **전역 100단계 100% 비중복(Global Unique) 엄격 유지**:
   - 100단계 전체에 걸쳐 단 하나의 단어도 다른 단계에서 중복 출제되지 않음.
   - 단계당 18~22단어 배치를 위해 총 고유 어휘 풀을 기존 1,787개에서 **2,400개 이상으로 대폭 확충**.
5. **오프라인 고음질 음성(MP3) 및 빌드 파이프라인 연동**:
   - 신규 추가 단어 및 문제 해설에 대한 음성 생성 및 `index.html` 완전 연동.

## 2. 세부 추진 전략 및 단계별 작업

### 2.1 [1단계] 시니어 친화 마스터 어휘 DB 대규모 확충 (1,787개 → 2,400개 이상)
- 기존 `vocabulary_1000.json` (1,787개)에 신규 검증 어휘 700개 이상 추가.
- `scripts/vocab/` 내에 신규 모듈 (`level_extra33.js` ~ `level_extra42.js`) 생성:
  - 2글자, 3글자, 4글자 중심의 정통 한국어, 세시풍속, 전통문화, 사자성어, 식물/동물, 일상어.
  - 교차 결합력이 우수한 빈출 음절(가, 나, 다, 라, 마, 바, 사, 아, 자, 차, 카, 타, 파, 하, 동, 산, 천, 백, 청 등) 적극 배치.
- `build_all.js`를 재실행하여 단어/해설 중복 0건의 2,400개 이상 완전 무중복 마스터 DB 구축.

### 2.2 [2단계] 초고밀도 10x10 퍼즐 생성 엔진 고도화 (`scripts/generator_10x10.js`)
1. **타깃 문항 수 및 밀도 임계값 대폭 상향**:
   - `targetWords`: 기본 18~22개 (단계별 18~22문항)
   - `minFilledCells`: 최소 46~48칸 이상
2. **사방 공간 분산 휴리스틱 (Spatial Dispersion)**:
   - 단어 추가 시, 아직 단어가 도달하지 않은 빈 영역(행/열)으로 뻗어나가는 교차점에 높은 우선순위 부여.
   - 최종 검증 시 `minR <= 1`, `maxR >= 8`, `minC <= 1`, `maxC >= 8`를 만족하여 격자 10x10 전체를 빈틈없이 채웠는지 판정.
3. **완전 연결망(100% Connected) 보장**:
   - 고립 단어 0건, 모든 단어가 1개 이상의 공통 음절로 상호 교차.

### 2.3 [3단계] 100단계 전수 생성 및 무중복 검증
- 100단계에 걸쳐 약 1,900~2,100개의 단어를 전역 무중복으로 일괄 생성.
- `scripts/verify_10x10.js`를 통해 전수 정합성 검증:
  - 100단계 완결성
  - 전역 단어/해설 중복 0건
  - 활성 칸 수 평균 48칸 이상 달성 여부
  - 철자/격자 정합성 100%

### 2.4 [4단계] 음성 생성 및 앱 번들 빌드 (`build_app.js`)
- 신규 단어 음성 MP3 사전 생성 (`scripts/generate_audio.js`).
- `index.html` 내 100단계 데이터 업데이트 및 서비스워커 캐시 버전 판올림 (`senior-crossword-100-v9`).
- 로컬 웹 서버 재실행 및 브라우저 검증.
- Git 커밋 및 GitHub 백업.
