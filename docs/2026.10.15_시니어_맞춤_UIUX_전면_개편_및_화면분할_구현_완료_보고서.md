# 2026.10.15 시니어 맞춤 UI/UX 전면 개편 및 화면분할 구현 완료 보고서

## 1. 개요 및 추진 배경
* **배경**: 스마트폰 환경에서 기존 가로세로 낱말 퍼즐을 실행했을 때, 상단 글자 크기 조절 버튼("크게")이 화면 우측으로 잘리고, 하단 핵심 조작 버튼([지우기], [전체], [힌트], [확인])이 화면 아래로 밀려 매번 스크롤해야만 입력할 수 있는 심각한 사용성 문제가 존재했습니다.
* **목표**:
  1. 단일 페이지(Single Screen)의 세로 높이 과부하(890~1,070px)를 해소하고, 스마트폰 뷰포트(650~780px) 내에 **스크롤 없이 100% 안착(No-Scroll Viewport)**되는 직관적 레이아웃 구축.
  2. 연세가 많으신 어르신(시니어)의 조작 편의를 위해 복잡한 상단 메뉴와 진행률 표시를 과감히 정리하고, **3개 독립 화면(메인 퍼즐, 100단계 진행 현황판, 환경설정 모달)**으로 기능 분할(Modular Multi-Screen Architecture).
  3. 모든 폰트 크기 조절 옵션 잘림을 원천 차단하고, 10x10 퍼즐 격자와 큼직한 한글 터치 자판, 3대 액션 버튼을 한눈에 바로 조작할 수 있도록 구현.

## 2. 3대 핵심 개편 및 화면분할 상세

### ① [화면 1] 메인 게임 화면: 무스크롤(No-Scroll Viewport) 100% 안착
* **초슬림 탑바 (42px)**:
  * 기존의 번잡했던 드롭다운 셀렉트 2개(스테이지, 레벨), 전체 진행률 바, 폰트 조절 버튼 3개를 상단에서 과감히 제거.
  * 좌측 `[☰ 단계목록]` 버튼 + 중앙 또렷한 단계명(`스테이지 1 - 1단계`) + 우측 `[🔊 소리]` & `[⚙ 설정]` 아이콘 버튼으로 압축 배치하여 상단 높이를 **155px ➔ 42px**로 대폭 슬림화(73% 절감).
* **10x10 격자 반응형 정사각 핏 (Fit-to-Screen)**:
  * 모바일 화면 폭과 잔여 높이에 맞춰 10x10 격자가 유연하게 리사이징되며, 중앙에 또렷한 고대비 테두리로 표시.
* **슬림형 문제 설명 & 인라인 글자 슬롯 카드 (54px)**:
  * 문제 방향 배지(`[⬇ 세로 1번 (3글자)]`) + 정답 글자수 조합 슬롯 + `[🔊 듣기]` 버튼을 한 줄에 통합 배치.
  * 굵고 짙은 폰트로 문제 본문을 시원하게 표시.
* **큼직한 한글 터치 자판 (2행 10버튼)**:
  * 손가락 떨림이나 시력 저하가 있으신 어르신도 오타 없이 누를 수 있도록 10개 음절 타일을 널찍하게 2행 배열.
* **하단 밀착형 3대 핵심 액션 바 (38px)**:
  * 불필요했던 [전체보기] 버튼을 제거하고, 가장 자주 쓰는 3개 버튼만 엄선:
    1. **`[⬅ 지우기]`** (연분홍 소프트 레드, 오타 정정)
    2. **`[💡 힌트]`** (연노랑 골드, 막혔을 때 한 글자 채우기)
    3. **`[✔ 확인]`** (고대비 코발트 블루, 즉시 정답 판정)
  * **결과: 세로 스크롤바가 1픽셀도 생기지 않고 모든 요소가 첫 화면에 100% 들어옴.**

### ② [화면 2] 스테이지 & 100단계 진행 현황판 (`#stageMapScreen`)
* **풀스크린 오버레이 분할**:
  * 메인 퍼즐 상단의 `[☰ 단계목록]` 또는 중앙 타이틀을 터치하면 부드럽게 전체 진행 현황판으로 전환.
* **100단계 전체 달성도 요약**:
  * 상단에 `🏆 전체 100단계 달성도: 0 / 100 단계 (0%)`와 부드러운 그린 프로그레스 바 제공.
* **10개 스테이지 & 100개 대형 타일**:
  * 스테이지 1 (새싹 입문)부터 스테이지 10 (신선 완성)까지 10개 섹션 카드 제공.
  * 각 스테이지마다 10개 단계 타일(2행 5열)이 큼직한 사각형 버튼으로 배치.
  * '도전 중(노란색)', '클리어 완료(연초록 도장 체크 ✔)' 상태가 실시간 반영되며, 원하는 단계를 터치하면 즉시 해당 퍼즐 화면으로 점프.
* **원터치 뒤로가기**:
  * 상단 대형 `[← 퍼즐로 돌아가기]` 버튼으로 언제든지 풀던 퍼즐로 복귀 가능.

---

### ③ [화면 3] 환경설정 및 안내 모달 (`#settingsModal`)
* **우측 상단 `[⚙]` 아이콘 버튼 터치 시 팝업**:
  1. **글자 크기 3단 선택 라디오 버튼**:
     * `[보통 글자]`, `[큰 글자]`, `[아주 큰 글자]`를 가로 3분할 넉넉한 공간에 배치하여 글자 잘림 현상을 원천적으로 해결.
     * 클릭 즉시 CSS 변수 `--font-scale`이 실시간 반응하여 퍼즐 글자 및 문제 폰트 확대.
  2. **음성 안내 토글**:
     * 문제 선택 시 TTS 자동 낭독 ON/OFF 간편 전환.
  3. **단계 초기화**:
     * `[🔄 현재 단계 처음부터 다시 풀기]` 기능으로 입력한 글자를 지우고 처음부터 깨끗하게 도전 가능.
  4. **시니어 친화적 쉬운 게임 방법 안내**:
     * 어르신 눈높이에 맞춘 친절한 4줄 사용 설명 탑재.
