# 2026.10.15 상단 브랜드바 구축 및 듣기버튼 오디오동작 개선 보고서

## 1. 개요
* **요청 사항**:
  1. 메인 퍼즐 화면 가장 상단에 퍼즐 아이콘과 앱 명칭을 멋있게 표현.
  2. 다섯 글자 답변 등 긴 단어 선택 시 문제 설명 카드의 `[듣기]` 버튼 이미지가 화면 밖으로 50% 정도 밀려나 잘리는 현상 수정.
  3. 퍼즐 및 문제 시작 시마다 자동으로 오디오(TTS)가 재생되어 불편했던 점을 개선하여, 사용자가 직접 `[문제 듣기]` 버튼을 터치했을 때만 음성이 재생되도록 수동 재생 방식으로 변경.

---

## 2. 주요 개선 내용

### ① 최상단 앱 명칭 & 브랜딩 바 (`.brand-bar`) 구축
* **위치**: 메인 퍼즐 컨테이너 최상단 (단계 조작 바 위)
* **디자인 요소**:
  * **배경**: 깊이감 있고 신뢰감을 주는 로열 블루 그라데이션 (`#1E3A8A` ➔ `#1D4ED8` ➔ `#2563EB`) 및 은은한 그림자.
  * **로고 & 명칭**: 에메랄드 퍼즐 아이콘(`🧩`) + 선명한 굵은 화이트 텍스트(`청춘`) + 눈에 띄는 골드 옐로우 하이라이트(`10×10`) + `낱말퍼즐`.
  * **시니어 특화 배지**: 우측에 반투명 골드 캡슐형 `어르신 두뇌 건강` 서브 배지 배치.
* **높이 최적화**: 28px 초슬림 높이로 구현하고 바로 아래 조작 탑바를 38px로 압축하여, 전체 화면 100vh 무스크롤(No-Scroll Viewport)을 완벽하게 유지.

---

### ② 5글자 단어 듣기 버튼 잘림 원천 해결 (3행 계층형 분리)
* **원인 분석**:
  * 기존에는 1행 안에 `[문제 태그]` + `[정답 슬롯 N개]` + `[듣기 버튼]` 3개 요소를 한꺼번에 가로로 늘어놓아, 5글자 단어의 경우 슬롯 너비(약 170px)로 인해 우측 끝 `[듣기]` 버튼이 스마트폰 화면 밖으로 50% 밀려남.
* **해결 구조**:
  1. **1행 (탑 로우)**: 좌측에 `[⬇ 세로 2번 (5글자)]` 방향/번호/글자수 배지, 우측에 `[🔊 문제 듣기]` 버튼을 양 끝 정렬(`justify-content: space-between`)로 배치.
     ➔ **결과: 어떤 길이의 단어가 나오더라도 `[문제 듣기]` 버튼이 카드 안쪽에 100% 온전히 안착되며 0픽셀의 잘림도 없음.**
  2. **2행 (문제 본문)**: 또렷하고 굵은 글씨의 문제 설명 텍스트 배치.
  3. **3행 (정답 슬롯)**: 정답 글자 조합 슬롯(`slots-container`)을 단독 행으로 분리하여 가로 전체 폭을 여유롭게 활용.
     ➔ 5글자, 6글자 단어도 가로 중앙에 넉넉하고 아름답게 정렬.

---

### ③ 오디오(TTS) 자동 재생 해제 및 수동 듣기 전환
* **개선 배경**: 문제 시작 및 단어 선택 시마다 기기 음성이 자동으로 흘러나와 당황스럽거나 시끄럽다는 피드백 반영.
* **적용 내용**:
  * `autoSpeak` 기본값을 `false`로 설정(`localStorage.getItem(STORAGE_KEY_AUTO_SPEAK) === 'true'`).
  * 단어 선택(`selectWord`) 시 자동 낭독 호출을 비활성화.
  * 오직 사용자가 `[🔊 문제 듣기]` 버튼을 직접 탭했을 때만 `speakCurrentClue()`가 호출되어 또렷하게 낭독하도록 변경.
  * 환경설정 모달(`settingsModal`)의 음성 안내 토글 기본 표시도 `꺼짐`으로 동기화.

* **테스트 환경**: 스마트폰 대표 뷰포트 (412 × 840px)
* **검증 결과 상세**:

| **5글자 단어 듣기 버튼** | 우측 화면 밖으로 50% 잘림 | 카드 우측 안쪽에 100% 온전 안착, **잘림 0%** | **완벽 해결** |
