## 3. 핵심 아키텍처 및 구현 세부사항

### ① 안드로이드 네이티브 WebView 래퍼
- **Kotlin + AndroidX 기반**의 경량 네이티브 컨테이너 구현.
- `file:///android_asset/index.html`을 즉각 로드하여 네트워크 지연 없이 0.1초 만에 화면이 표시됩니다.
- 로컬 스토리지(LocalStorage) 및 DOM 스토리지를 활성화하여 문제 풀이 진행 상황, 글자 크기 설정 등이 앱을 껐다 켜도 영구 보존됩니다.

### ② 2,067개 전 문항 음성(MP3) 오프라인 패키징
- 시니어 음성 안내에 필요한 2,067개의 고품질 음성 MP3 파일(약 110MB)을 APK 내부의 `assets/audio/` 폴더에 완벽히 임베딩했습니다.
- 비행기 탑승 모드나 데이터 요금제가 없는 와이파이 전용 기기에서도 "문제 듣기" 기능이 원활하게 작동합니다.

### ③ 시니어 친화적 시스템 뒤로가기(Back Button) 제어
- 스마트폰의 '뒤로가기' 제스처 또는 버튼 입력 시:
  1. 퍼즐 진행 현황판, 환경설정, 정답 모달창 등이 열려있으면 **화면을 종료하지 않고 팝업만 먼저 닫아주는 안전 처리**를 수행합니다.
  2. 메인 화면 상태에서 뒤로가기를 누르면 즉시 종료되지 않고 *"한 번 더 누르면 종료됩니다"*라는 시니어용 안내 토스트가 표시되며, 2초 내 재입력 시에만 종료됩니다.

### ④ 로열 블루 풀스크린 시스템 바 테마
- 상단 상태 표시줄(Status Bar)과 하단 탐색줄(Navigation Bar)을 앱의 브랜드 색상인 **로열 블루(#1D4ED8)**로 통일하여 몰입감 높은 화면을 제공합니다.

## 4. 스마트폰 간편 설치 방법

스마트폰에 생성된 APK를 설치하는 방법은 다음과 같습니다:

1. **파일 전송**:
   - `C:\Antigravity\Crossword_puzzle\청춘10x10낱말퍼즐_100.apk` 파일을 스마트폰으로 복사합니다.
   - 방법: PC와 스마트폰을 USB 케이블로 연결하여 '다운로드(Download)' 폴더로 복사하거나, 카카오톡 '나와의 채팅' / 구글 드라이브 / 이메일로 전송합니다.
2. **설치 실행**:
   - 스마트폰의 **'내 파일'** 앱 또는 다운로드 받은 채팅창에서 해당 APK 파일을 터치합니다.
3. **'출처를 알 수 없는 앱 설치' 허용**:
   - 플레이스토어 외부에서 직접 설치하는 파일이므로 보안 확인 창이 뜹니다.
   - **"이 출처 허용"** 또는 **"무시하고 설치"**를 선택하시면 정상적으로 설치가 완료됩니다.
4. **실행**:
   - 스마트폰 홈 화면 또는 앱 서랍에 **"청춘 10x10 낱말퍼즐"** 아이콘이 생성되며, 터치하시면 즉시 즐기실 수 있습니다.

# 안드로이드 빌드 실행
cd "C:\Antigravity\Crossword_puzzle\android"
.\gradlew.bat assembleDebug

# 완성된 APK 복사
