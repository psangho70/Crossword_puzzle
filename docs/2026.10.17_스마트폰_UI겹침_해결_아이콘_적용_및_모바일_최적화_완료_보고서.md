## 1. 개요 및 목적

실제 스마트폰 기기에 설치했을 때 발생하던 **최상단 시스템 상태바(시계, 배터리)와 앱 타이틀의 겹침**, **최하단 소프트웨어 내비게이션 바(홈, 뒤로가기)와 조작 버튼(`지우기`, `힌트`, `확인`)의 겹침** 문제를 원천 해결하고, `icon.svg` 기반의 고품질 전용 앱 아이콘과 시니어 맞춤형 모바일 6대 최적화를 적용한 신규 **v1.0.1 APK**를 빌드하여 배포합니다.

## 2. 세부 개선 내역 비교표

| 개선 항목 | 개선 전 (v1.0.0) | 개선 후 (v1.0.1) | 기술적 구현 내용 |
| :--- | :--- | :--- | :--- |
| **최상단 상태바 겹침** | 통신사, 시계, 배터리가 파란색 브랜드 바와 겹쳐 텍스트 판독 불가 | 상태바 바로 아래로 앱 브랜드 바가 깨끗하게 내려와 **겹침 0% 완벽 분리** | `ViewCompat.setOnApplyWindowInsetsListener`로 `statusBars().top` 높이를 동적 감지하여 상단 안전 여백 부여 |
| **최하단 소프트키 겹침** | 하단 3버튼(`|||`, `○`, `<`)이 `지우기, 힌트, 확인` 버튼 위를 가려 오작동 유발 | 소프트키 영역 위에 조작 버튼이 온전히 안착되어 **손가락 오터치 원천 차단** | `navigationBars().bottom` 높이만큼 웹뷰 하단 마진을 부여하여 하단 안전 영역(Safe Area) 확보 |
| **앱 런처 아이콘** | 안드로이드 기본 초록색 로봇 아이콘 표시 | **청춘 10×10 낱말퍼즐 전용 고품질 브랜드 아이콘** 표시 | `icon.svg` 기반 최신 Adaptive Icon 벡터 드로어블 및 전 해상도(mdpi, hdpi, xhdpi, xxhdpi, xxxhdpi) PNG 탑재 |
| **화면 자동 꺼짐 (Sleep)** | 15~30초 고민 중 화면이 자꾸 꺼져 매번 화면을 켜야 함 | 퍼즐 실행 중에는 **화면이 꺼지지 않고 항상 켜짐 유지** | `window.addFlags(FLAG_KEEP_SCREEN_ON)` 적용으로 시니어의 장고 시간 배려 |
| **화면 가로 회전** | 비스듬히 눕거나 폰을 기울일 때 화면이 돌아가 레이아웃 깨짐 | 언제나 **안정적인 세로 모드(Portrait)로 화면 고정** | `AndroidManifest.xml`에 `screenOrientation="portrait"` 선언 |
| **더블 탭 확대 오작동** | 버튼이나 자판을 빠르게 연타할 때 화면이 200% 확대되어 튕김 | 연타 시에도 **화면 확대 없이 쾌적한 터치 반응 유지** | CSS `touch-action: manipulation` 및 웹뷰 줌 컨트롤(`setSupportZoom(false)`) 차단 |
| **텍스트 롱 터치 팝업** | 지문이나 퍼즐을 길게 누르면 시스템 '복사/검색' 팝업이 가림 | 길게 터치해도 **불필요한 시스템 복사 툴바 원천 차단** | `user-select: none`, `-webkit-touch-callout: none` 전역 적용 |
| **물리 볼륨 버튼 연동** | 볼륨 버튼을 누르면 통화 벨소리가 조절되어 음성 소리를 못 키움 | 볼륨 버튼 조작 시 **'문제 듣기' 음성 미디어 볼륨이 즉각 조절** | `volumeControlStream = AudioManager.STREAM_MUSIC` 지정 |
| **시스템 가상 자판 간섭** | 화면 터치 시 스마트폰 기본 쿼티 키보드가 올라와 화면을 가림 | 자체 10글자 한글 자판만 동작하며 **시스템 키보드 완전 차단** | `windowSoftInputMode="stateAlwaysHidden"` 지정 |
