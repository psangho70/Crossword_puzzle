# 2026.10.14 시니어 맞춤형 7x7 한국어 가로세로 낱말 퍼즐 100단계 PWA 웹앱 구축 및 배포

## 1. 프로젝트 개요
- **목표**: 어르신(시니어)을 위한 고대비, 큰 글자, 큼직한 터치 자판, 음성 안내(TTS) 및 경쾌한 효과음을 갖춘 7x7 100단계 한국어 가로세로 낱말 퍼즐 웹앱 제작 및 GitHub Pages 배포
- **타겟 GitHub 레포지토리**: `https://github.com/psangho70/Crossword_puzzle.git`
- **배포 브랜치**: `main`
- **배포 URL**: `https://psangho70.github.io/Crossword_puzzle/`
- **기술 스택**: 순수 Vanilla HTML5, CSS3, ES6+ JavaScript, Web Audio API, Web Speech Synthesis, Cache-First Service Worker PWA

## 2. 생성 및 배포된 핵심 파일 목록
1. **`index.html`**
   - 시니어 맞춤 고대비 컬러 시스템 (미색 배경 `#FAF8F5`, 선명한 파란색 `#1D4ED8`, 하이라이트 노란색 `#FEF08A`, 정답 초록색 `#DCFCE7`)
   - 3단 글자 크기 조절 (`작게` / `중간` / `크게`) 및 격자판 레이아웃 밀림 방지 설계
   - 10개 스테이지 × 10단계 = 총 100단계 퍼즐 데이터 및 엔진 통합
   - 모바일 기본 키보드가 뜨지 않는 '10개 대형 한글 음절 터치 키보드(5열×2행, 54px 이상)'
   - 정답 슬롯 자동 채움, 잠금 슬롯, 자동 정답 판별, 다음 미해결 문제 자동 포커스
   - Web Audio API 기반 효과음 (터치음, 정답 팡파르, 오답 알림음, 단계 클리어 축하 화음)
   - `window.speechSynthesis` 기반 한국어 음성 문제 낭독 (0.92 배속)
   - LocalStorage 실시간 자동 저장 및 진행률 표시
   - PWA 홈 화면 추가 유도 배너
2. **`manifest.json`**
   - `name`: "청춘 7x7 가로세로 낱말 퍼즐 100"
   - `short_name`: "청춘낱말퍼즐"
   - `display`: "standalone"
   - `orientation`: "portrait"
   - 테마 및 배경 색상 지정
3. **`sw.js`**
   - Cache-First 서비스 워커 구현 (`senior-crossword-100-v2`)
   - 네트워크 연결이 없는 오프라인 상태에서도 100% 정상 구동
4. **`icon.svg`**
   - 512x512 고대비 청춘 낱말 퍼즐 2x2 벡터 타일 아이콘
5. **`.github/workflows/pages.yml`**
   - GitHub Pages 자동 배포 CI/CD 워크플로우
6. **`README.md`**
   - 프로젝트 소개, 주요 기능, 구조 및 GitHub Pages 링크 명시

## 3. 스마트폰 모바일 최적화 및 문제 듣기(TTS) 개선 사항 (2026.10.14)
1. **모바일 상단 헤더 줄바꿈 문제 해결**:
   - `white-space: nowrap;` 및 `flex-shrink: 0;` 적용으로 타이틀, 뱃지, 소리 버튼, 글자 크기 버튼이 세로로 찌그러지거나 분리되지 않고 가로 1행으로 깔끔하게 정렬되도록 전면 수정.
   - 여백 및 패딩 컴팩트화로 7x7 보드판과 10개 한글 음절 터치 자판이 스마트폰 한 화면에 시원하게 표시되도록 반응형 높이 조절.
2. **스마트폰(Android/PWA) TTS 문제 듣기 호환성 해결**:
   - **가비지 컬렉션(GC) 방지**: 안드로이드 크롬에서 음성 재생 도중 인스턴스가 회수되어 무음 처리되던 버그를 해결하기 위해 `window.__currentUtterance` 전역 변수에 명시적 참조 보존.
   - **한국어 Voice 매핑**: `speechSynthesis.onvoiceschanged` 및 `getVoices()`를 통해 한국어 음성(ko-KR)을 감지하여 `utter.voice`에 우선 할당.
   - **오디오 세션 보정**: `speechSynthesis.resume()` 및 `speechSynthesis.cancel()` 호출 타이밍 보정 및 시작 알림 챠임벨 연동.
3. **서비스 워커 캐시 갱신 (`v2`)**:
   - 기기 홈 화면에 추가된 PWA에서도 최신 코드 및 레이아웃이 즉시 갱신되도록 `sw.js`의 캐시 버전을 `v2`로 업데이트.
