# 2026.10.14 시니어 맞춤형 7x7 한국어 가로세로 낱말 퍼즐 100단계 PWA 웹앱 구축 및 배포

## 1. 프로젝트 개요
- **목표**: 어르신(시니어)을 위한 고대비, 큰 글자, 큼직한 터치 자판, 음성 안내(TTS) 및 경쾌한 효과음을 갖춘 7x7 100단계 한국어 가로세로 낱말 퍼즐 웹앱 제작 및 GitHub Pages 배포
- **타겟 GitHub 레포지토리**: `https://github.com/psangho70/Crossword_puzzle.git`
- **배포 브랜치**: `main`
- **배포 URL**: `https://psangho70.github.io/Crossword_puzzle/`
- **기술 스택**: 순수 Vanilla HTML5, CSS3, ES6+ JavaScript, Web Audio API, Web Speech Synthesis, Cache-First Service Worker PWA

## 2. 생성 및 배포된 핵심 파일 목록
1. **`index.html`**
   - 시니어 맞춤 고대비 컬러 시스템 (미색 배경 `#FAF8F5`, 선명한 파란색 `#1D4ED8`, 하이라이트 노란색 `#FEF08A`, 정답 초록색 `#DCFCE7`)
   - 3단 글자 크기 조절 (`작게` / `중간` / `크게`) 및 격자판 레이아웃 밀림 방지 설계
   - 10개 스테이지 × 10단계 = 총 100단계 퍼즐 데이터 및 엔진 통합
   - 모바일 기본 키보드가 뜨지 않는 '10개 대형 한글 음절 터치 키보드(5열×2행, 54px 이상)'
   - 정답 슬롯 자동 채움, 잠금 슬롯, 자동 정답 판별, 다음 미해결 문제 자동 포커스
   - Web Audio API 기반 효과음 (터치음, 정답 팡파르, 오답 알림음, 단계 클리어 축하 화음)
   - **모바일 100% 호환 하이브리드 고음질 한국어 TTS 엔진 (Google Translate 음성 스트리밍 1순위 + 네이티브 SpeechSynthesis 2순위 자동 폴백)**
   - LocalStorage 실시간 자동 저장 및 진행률 표시
   - PWA 홈 화면 추가 유도 배너
2. **`manifest.json`**
   - `name`: "청춘 7x7 가로세로 낱말 퍼즐 100"
   - `short_name`: "청춘낱말퍼즐"
   - `display`: "standalone"
   - `orientation`: "portrait"
   - 테마 및 배경 색상 지정
3. **`sw.js`**
   - Cache-First 서비스 워커 구현 (`senior-crossword-100-v3`)
   - 외부 TTS 오디오 스트림 요청은 브라우저 기본 네트워크로 통과시켜 끊김 없는 오디오 재생 보장
4. **`icon.svg`**
   - 512x512 고대비 청춘 낱말 퍼즐 2x2 벡터 타일 아이콘
5. **`.github/workflows/pages.yml`**
   - GitHub Pages 자동 배포 CI/CD 워크플로우
6. **`README.md`**
   - 프로젝트 소개, 주요 기능, 구조 및 GitHub Pages 링크 명시

## 3. 스마트폰 모바일 문제 듣기(TTS) 무음 원인 및 해결 상세
- **근본 원인**:
  1. **안드로이드 기기별 TTS 엔진 편차**: PC 윈도우에는 한국어 TTS 음성팩이 기본 내장되어 있어 항상 동작하지만, 삼성/LG/샤오미 등 안드로이드 스마트폰은 기기 설정에 따라 Google TTS/삼성 음성 엔진이 꺼져 있거나 한국어 음성 데이터가 미설치된 경우가 많아 네이티브 Web Speech API(`speechSynthesis`)가 무음 처리되거나 에러를 발생시킴.
  2. **모바일 Autoplay / 사용자 제스처(User Activation) 제한**: 모바일 브라우저는 `setTimeout` 등 비동기 지연 내에서 오디오/음성을 호출하면 보안 정책상 소리를 차단함.
  3. **서비스 워커 캐싱 간섭**: 이전 서비스 워커가 외부 오디오 요청까지 가로채려 하여 오디오 스트리밍이 정상 수신되지 못함.
- **해결 조치**:
  1. **하이브리드 한국어 오디오 스트리밍 엔진 탑재**:
     - 사용자 클릭 시 동기(Synchronous) 스택 내에서 즉시 고음질 한국어 오디오 스트림(`Audio` 객체)을 생성하고 스마트폰의 **미디어 볼륨 채널**로 100% 확실하게 소리를 출력하도록 구현.
     - 기기 내 TTS 엔진 설치 여부와 상관없이 맑고 또렷한 표준 한국어 여성 성우 발음으로 문제를 정확히 낭독.
  2. **네이티브 SpeechSynthesis 2차 폴백 유지**:
     - 오프라인 상태(비행기 모드) 등 네트워크 연결이 없을 경우 자동으로 기기 내장 `speechSynthesis`로 전환.
  3. **서비스 워커 `sw.js` 개선 (v3)**:
     - `event.request.url.startsWith(self.location.origin)`를 적용하여 외부 TTS 오디오 스트림은 서비스 워커 간섭 없이 브라우저 기본 네트워크로 직통 연결되도록 보장.
  4. **시각적 음량 안내 토스트 추가**:
     - 음성 재생 중 `"🔊 문제를 읽어드립니다 (소리가 안 나면 기기 미디어 음량을 올려주세요)"` 안내 토스트를 화면에 표시하여 사용자 경험 향상.
