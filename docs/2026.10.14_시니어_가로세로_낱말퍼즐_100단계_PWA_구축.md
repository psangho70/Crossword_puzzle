- **타겟 GitHub 레포지토리**: `https://github.com/psangho70/Crossword_puzzle.git`
- **배포 브랜치**: `main`
- **배포 URL**: `https://psangho70.github.io/Crossword_puzzle/`
- **기술 스택**: 순수 Vanilla HTML5, CSS3, ES6+ JavaScript, Web Audio API, Web Speech Synthesis, Cache-First Service Worker PWA

## 4. PC 및 스마트폰 음성 안내(TTS) 무음 근본 원인 규명 및 W3C Web Speech API 완전 최적화 (2026.10.14)
- **근본 원인 분석**:
  1. **Google TTS 외부 엔드포인트의 CORS 차단 및 User Gesture 권한 만료**:
     - `translate.google.com/translate_tts`는 브라우저 클라이언트 환경(GitHub Pages 등 타 도메인 Referer)에서 직접 오디오 스트림을 요청할 경우 **CORS 차단 및 HTTP 403 Forbidden**을 반환함.
     - 이로 인해 `Audio.play()`가 실패하고 비동기 콜백(`catch`/`onerror`)으로 넘어가면서, 브라우저 보안 정책상 **'사용자 제스처(User Activation/Gesture)' 토큰이 즉시 만료**됨.
     - 그 결과 2순위로 호출된 `SpeechSynthesis` 역시 브라우저에 의해 호출이 차단(Silent Drop)되어, **스마트폰뿐만 아니라 PC 브라우저에서도 완전히 무음**이 되는 현상이 발생함.
  2. **Chromium 엔진의 고질적 `speechSynthesis.cancel()` 큐 제거 버그 (Chromium Issue 995910)**:
     - `cancel()`을 호출한 직후 같은 실행 루프에서 `speak(utter)`를 호출하면, 브라우저 내부 C++ 큐 처리 타이밍 이슈로 인해 **방금 큐에 등록한 새 발화까지 함께 취소**되어 아무 소리도 나지 않는 치명적인 버그가 존재함.
  3. **목소리 매칭 오류 및 안드로이드 크롬 가비지 컬렉터(GC) 수거 버그**:
     - `speechSynthesis.getVoices()`에서 한국어가 매칭되지 않았을 때 임의의 기본 음성(영어 등)이 강제 할당되어 음성이 깨지거나 침묵함.
     - 안드로이드 크롬에서 `Utterance` 인스턴스가 함수 스코프 내 로컬 변수로만 존재하면 발화 도중 GC에 의해 소멸되어 재생이 중단되는 문제.

- **완전한 근본 개선 조치**:
  1. **외부 차단 API 의존성 100% 제거 & 순수 W3C Web Speech API 단일화**:
     - 외부 도메인 호출 및 CORS 에러 위험을 완전히 배제하고 브라우저 네이티브 `window.speechSynthesis` 표준으로 단일화.
     - 사용자 클릭/터치 이벤트 핸들러의 **완전한 동기적(Synchronous) 실행 컨텍스트** 내에서 `speak(utter)`를 즉각 실행하여 브라우저의 오디오 정책을 무조건 통과.
  2. **`cancel()` 무조건 호출 버그 제거 및 토글식 안전 제어**:
     - 발화 시작 시 무차별 `cancel()` 호출을 완전히 제거.
     - 오직 사용자가 "듣기 중지" 버튼을 누르거나 발화 완료(`onend`), 오류(`onerror`) 시에만 `cancel()`을 안전하게 호출하도록 수정.
  3. **한국어 전용 보이스 필터링 및 fallback 안전화**:
     - `getKoreanVoice()` 함수를 구현하여 시스템 보이스 목록 중 `ko-KR`, `ko`, `korean`, `한국어`로 등록된 음성만 정확히 선별하여 바인딩. 한국어 보이스가 명시되어 있지 않은 환경에서는 임의의 영문 음성을 덮어씌우지 않고 `utter.lang = 'ko-KR'` 로캘 매핑에 위임.
  4. **스마트폰 미디어 오디오 하드웨어 Unmute (Web Audio 연동)**:
     - 버튼 터치 즉시 `sound.playTap()` (Web Audio API)를 재생하여 스마트폰 OS의 오디오 세션을 즉시 깨우고(AudioContext Unlock), 사용자에게 기기 미디어 볼륨이 켜져 있는지 청각적 피드백을 제공.
  5. **안드로이드 크롬 GC 방어 및 킵얼라이브 타이머**:
     - `window.__currentUtterance = utter;` 전역 참조를 유지하여 GC 조기 수거 방지.
     - 발화 중 3초 주기로 `window.speechSynthesis.resume()`을 찔러주는 킵얼라이브 타이머 탑재.
  6. **PWA 서비스 워커 v4 갱신 (`senior-crossword-100-v4`)**:
     - 스마트폰 PWA 및 브라우저에서 구버전 캐시를 즉각 무효화하고 최신 스크립트가 실행되도록 보장.
