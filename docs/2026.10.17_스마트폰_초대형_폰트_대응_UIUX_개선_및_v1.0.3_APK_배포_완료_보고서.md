## 1. 개요 및 배경

어르신(시니어) 사용자께서 스마트폰 시스템 설정에서 **"글자 크기(Font Scale)"를 '매우 크게' 또는 최대로 설정**했을 때 발생하던 치명적인 결함을 완벽하게 해결했습니다:
1. **10×10 퍼즐 격자판의 맨 아랫줄(10행, 17번 문항)이 하단 문제 카드에 덮여 가려져 게임 진행이 불가능하던 현상**
2. **최상단 브랜딩 바(`brand-bar`) 텍스트가 2단으로 줄바꿈되며 서로 겹치고 우측 뱃지가 잘려나가던 현상**

단순히 시스템 확대를 차단하는 것에 그치지 않고, **"눈이 침침한 어르신을 위해 퍼즐 판은 안전하게 지키면서 문제 설명 글씨는 원터치로 시원하게 키워볼 수 있는 3단계 퀵 확대 시스템"**을 구현하여 접근성과 조작성을 모두 완벽하게 갖춘 최신 **v1.0.3 APK**를 빌드하여 배포합니다.

## 2. 세부 개선 내역 비교표

| 개선 항목 | 개선 전 (v1.0.2) | 개선 후 (v1.0.3) | 기술적 구현 내용 |
| :--- | :--- | :--- | :--- |
| **시스템 폰트 무제한 상속 차단** | 스마트폰 글자 크기(150~200%)가 웹뷰 전체에 여과 없이 상속되어 레이아웃 붕괴 | 웹뷰 전체 골격은 기준 비율을 엄격히 유지하여 **레이아웃 파괴 원천 차단** | `MainActivity.kt` 내 `settings.textZoom = 100` 명시 적용 |
| **10×10 격자판 10행 가림 결함** | 문제 카드가 위로 비대하게 커지며 10행(17번 문항)을 덮어 가림 | 어떤 해상도/폰트 크기에서도 **100개 칸 전체가 항상 100% 온전히 노출** | `.board-card`에 `flex: 1 1 auto; overflow: hidden; z-index: 1;` 적용 및 `.board-grid` 크기 자동 맞춤 |
| **최상단 브랜딩 바 겹침** | 타이틀 폰트가 2배 커져 `청춘`과 `낱말퍼즐`이 2단으로 겹치고 뱃지 잘림 | 폰트가 커져도 1줄로 단정하게 유지되어 **글자 겹침 0% 완벽 방지** | `.brand-bar`, `.brand-title` 등에 `white-space: nowrap !important;` 및 고정 폰트 크기 적용 |
| **단서 설명 카드 영역** | 글자가 길거나 커지면 세로 높이를 200px 이상 무제한 점유 | 카드 최대 높이를 세로 25%로 제한하고 **카드 내부에서 부드럽게 스크롤** | `.clue-card`에 `max-height: 25vh;`, `.clue-text`에 `max-height: 52px; overflow-y: auto;` 적용 |
| **시니어 전용 단서 글자 조절** | 설정 메뉴에 들어가야만 조절 가능하여 어르신이 찾기 어려움 | 문제 카드 바로 위에서 **[🔍 글자 보통/크게/특대] 3단계 원터치 전환** | `.clue-top-row`에 `btnClueFontQuick` 원터치 토글 탑재 (1.0x ➔ 1.15x ➔ 1.30x 순환) |
| **청각적 접근성 (TTS)** | 버튼 시인성이 낮고 일일이 터치해야 하는 불편함 | **밝은 고대비 문제 듣기 버튼** & 문제 선택 시 자동 낭독 연계 | TTS 버튼 시인성 강화 및 `autoSpeak` 자동 음성 읽기 모드 지원 |
