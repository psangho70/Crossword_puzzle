# 청춘 10x10 가로세로 낱말 퍼즐 100 🧩

어르신(시니어)을 위한 고대비 큰 글자, 10x10 대형 격자판, 큼직한 터치 자판, 사전 생성 MP3 문제 음성 안내 및 경쾌한 효과음을 갖춘 100단계 한국어 가로세로 낱말 퍼즐 PWA 웹앱입니다.

🔗 **서비스 바로가기**: [https://psangho70.github.io/Crossword_puzzle/](https://psangho70.github.io/Crossword_puzzle/)

---

## 🌟 주요 특징 및 전면 개선 내용

1. **10x10 대형 퍼즐 격자판 & 시니어 맞춤형 고대비 UI**
   - 시력이 약한 어르신을 위해 퍼즐 격자를 **10×10**으로 전면 확대
   - 화면 폭을 최대한 활용하는 반응형 그리드 및 또렷한 굵은 글꼴 적용
   - 퍼즐판 내부 셀은 물론, 현재 선택된 단어를 크고 시원하게 보여주는 **'정답 조합 슬롯'** 제공
   - 눈의 피로를 덜어주는 미색 배경(`#FAF8F5`)과 **`작게` / `중간` / `크게`** 3단계 글자 크기 즉시 조절 기능

2. **100단계 전체 100% 무중복 어휘 & 문항 수 대폭 증대**
   - **총 1,105개 고유 시니어 어휘 데이터베이스** 구축
   - 100단계 전체에 걸쳐 사용되는 **900개 문제/단어가 단 하나도 중복되지 않음 (중복률 0.0%)**
   - 스테이지 진행에 따라 단계별 문항 수 및 난이도 체계적 확장:
     - 스테이지 1 ~ 3: 단계당 8문항 (입문/기초)
     - 스테이지 4 ~ 7: 단계당 9문항 (중급/심화)
     - 스테이지 8 ~ 10: 단계당 10문항 (고급/도전)

3. **스마트폰 환경에서도 100% 완벽 동작하는 '문제 듣기' (사전 생성 MP3)**
   - 기기별 브라우저 TTS 엔진 차이나 한국어 음성 미설치 문제에 영향을 받지 않도록, 900개 전체 문항에 대한 고품질 한국어 음성을 사전 생성하여 연결
   - 서비스 워커(`sw.js`) Range(206) 스트리밍 캐싱을 통해 모바일에서도 끊김 없이 재생

4. **스마트폰 기본 키보드가 필요 없는 '10음절 대형 터치 자판'**
   - 모바일 기본 키보드가 화면을 가리지 않도록, 하단에 10개의 큼직한 한글 음절 버튼(5열×2행) 터치로 입력
   - 교차로 이미 맞힌 글자는 슬롯에 초록색 잠금 상태로 자동 반영
   - 슬롯이 다 채워지면 자동으로 정답을 판별하여 다음 미해결 문제로 자동 포커스
   - `지우기`, `전체 지우기`, `💡 한 글자 힌트` 지원

5. **경쾌한 사운드 & 자동 저장 & PWA 오프라인 지원**
   - Web Audio API 기반의 터치음, 정답 팡파르(도-미-솔-도), 오답음, 스테이지 클리어 축하 화음
   - LocalStorage를 통해 진행 단계, 클리어 목록, 글자 크기/소리 설정 실시간 저장
   - Cache-First 서비스 워커 탑재로 네트워크 연결이 없어도 100% 오프라인 플레이 지원

## 📁 디렉토리 및 파일 구조

```
Crossword_puzzle/
├── index.html                 # 메인 웹앱 UI, 스타일, 10x10 100단계 퍼즐 엔진 통합 빌드본
├── manifest.json              # PWA 매니페스트 (10x10 메타데이터, standalone 모바일 세로 고정)
├── sw.js                      # Cache-First 서비스 워커 (v6, MP3 오디오 Range 스트리밍 캐시)
├── icon.svg                   # 512x512 고대비 청춘 낱말 퍼즐 벡터 아이콘
├── audio/                     # 900개 전 문항 고품질 문제 듣기 사전 생성 MP3 파일 보관소
├── scripts/
│   ├── vocab/                 # 난이도별(1~5단계, 특화) 1,105개 고유 어휘 모듈
│   ├── vocabulary_1000.json   # 1,105개 검증 완료 시니어 어휘 DB
│   ├── generator_10x10.js     # 10x10 백트래킹 100단계 무중복 퍼즐 생성 엔진
│   ├── verify_10x10.js        # 100단계 900문항 전수 무중복 유효성 검증기
│   ├── puzzles_100_10x10.json # 100단계 10x10 완성 퍼즐 데이터셋 (900문항, 중복 0건)
│   ├── generate_audio.js      # 900개 문항 MP3 음성 병렬 사전 생성기
│   ├── build_app.js           # 10x10 PWA index.html 원클릭 통합 빌더
│   └── server.js              # 로컬 테스트용 HTTP 정적 파일 서버
└── docs/                      # 개발 기획서 및 일자별 작업 완료 보고서
```
