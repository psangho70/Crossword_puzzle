## 🌟 핵심 시니어 배려 7대 특화 기능

### 1. 10×10 대형 퍼즐 격자판 & 100단계 900문항 전수 무중복 어휘 체계
- **10×10 광폭 격자판**: 기존 8×8 대비 퍼즐판을 10×10으로 대폭 확대하여 시력이 약한 어르신도 시원하게 조망 가능.
- **총 1,105개 엄선 시니어 어휘 DB**: 백트래킹 퍼즐 자동 배치 엔진(`scripts/generator_10x10.js`)으로 100단계를 전수 구축.
- **900문항 100% 무중복 (중복률 0.0%)**: 1단계부터 100단계까지 사용된 모든 문제/단어가 단 한 번씩만 등장하여 지루함 없이 매 단계 신선한 두뇌 훈련 제공.
  - **스테이지 1 ~ 3**: 단계당 8문항 (기초/입문)
  - **스테이지 4 ~ 7**: 단계당 9문항 (중급/심화)
  - **스테이지 8 ~ 10**: 단계당 10문항 (고급/도전)

### 2. 스마트폰 초대형 폰트(최대 200%) 설정 완벽 대응 (4-Tier 폰트 방어 체계)
어르신들이 스마트폰 OS 설정에서 **글자 크기를 최대로 키우거나 디스플레이를 확대(150% ~ 200%)**해도 레이아웃이 겹치거나 잘리지 않는 무결점 UI를 제공합니다.
- **Tier 1 (브라우저 자동 확대 보정 방지)**: `text-size-adjust: none`, `-webkit-text-size-adjust: none` 적용.
- **Tier 2 (디자인 규격 고정)**: 레이아웃 중요 수치를 `rem` 단위로 고정하여 OS 시스템 글꼴 크기 변경의 무차별적 파급 효과 차단.
- **Tier 3 (Flex 축소 방지)**: 상하단 헤더, 문제 카드, 자판 영역에 `flex-shrink: 0` 및 `min-height`를 지정하여 텍스트 확대 시에도 버튼이 찌그러지거나 잘리지 않음.
- **Tier 4 (유연한 가변 패딩)**: CSS `clamp()`를 통해 다양한 해상도와 글자 확대 배율에 맞추어 마진과 여백 자동 최적화.
- **앱 내 3단계 돋보기 지원**: 앱 상단에서 어르신이 직접 `작게` / `보통` / `크게` 3단계로 글자 크기를 즉시 조절 가능.

### 3. 상하 2분할(2-Zone) 직관적 시니어 UI/UX
- **상단 영역 (조망 & 슬롯)**: 10×10 퍼즐 격자판과 함께, 현재 선택된 단어를 큼직하게 보여주는 **'정답 조합 슬롯'** 배치.
- **하단 영역 (문제 & 입력)**: 눈부심 없는 아이보리 미색 배경(`#FAF8F5`)의 문제 설명 카드와 10개의 대형 한글 음절 버튼이 있는 가상 키패드 상시 고정.

### 4. 900문항 사전 생성 MP3 고품질 음성 안내 (100% 오프라인 지원)
- **기기별 TTS 엔진 편차 원천 차단**: 기기 브라우저나 스마트폰의 한국어 TTS 엔진 미설치 문제에 구애받지 않도록, 900개 전 문항에 대해 자연스러운 고품질 한국어 MP3 오디오를 사전 생성하여 탑재.
- **오디오-입력 상호작용 최적화**: 문제 듣기 낭독 중 자판을 터치하여 정답을 입력하거나 슬롯이 채워지는 즉시 재생 중인 오디오를 강제 중지하여 청각적 혼선 방지.
- **PWA 오프라인 캐싱**: Service Worker(v6)의 HTTP 206 Range 스트리밍 캐싱을 통해 인터넷이 끊겨도 오디오가 끊김 없이 즉시 재생.

### 5. 모바일 기본 키보드가 필요 없는 '10음절 대형 터치 자판'
- 스마트폰 기본 가상 키보드가 팝업되어 퍼즐판을 가리는 문제를 원천 방지.
- 화면 하단에 큼직한 10개 음절(5열×2행) 터치 버튼 제공.
- 교차로 이미 풀린 글자는 초록색 자물쇠 잠금 상태로 자동 반영.
- 슬롯이 모두 채워지면 즉시 자동 판정(정답 팡파르 연출) 후 다음 미해결 문제로 자동 포커스 이동.
- `지우기`, `전체 지우기`, `💡 한 글자 힌트` 원터치 보조 기능 탑재.

### 6. GHAILab CI & 청춘 낱말 퍼즐 통합 브랜드 아이콘
- GHAILab 연구소 CI 로고와 선명한 가로세로 낱말 타일을 결합한 고해상도 브랜드 아이콘(`icon_512.png`, `icon_512_round.png`) 제작.
- 스마트폰 홈 화면 추가 및 안드로이드 설치 시 원형/적응형(Adaptive) 아이콘 완벽 지원.
- 상단 헤더에 GHAILab 심볼 및 브랜드 로고 상시 고정.

### 7. 안드로이드 네이티브 앱 (v1.0.3 배포)
- Google Play 스토어 및 사이드로딩 설치가 가능한 네이티브 APK 구축 완료 (`android/`).
- Kotlin 기반 WebView 하이브리드 앱으로, 안드로이드 시스템 폰트 확대 강제 적용을 방지하기 위해 `settings.textZoom = 100` 및 하드웨어 뒤로가기 버튼 최적화.

## 🛠️ 실행 및 빌드 가이드

### 1. 로컬 웹 서버 실행 (테스트)
Node.js 내장 정적 파일 서버를 실행하여 브라우저에서 즉시 테스트할 수 있습니다:
```bash
node scripts/server.js
# 브라우저에서 http://localhost:8080 접속
```

### 2. 10x10 무중복 퍼즐 생성 및 전수 검증
어휘 DB를 바탕으로 100단계 900문항을 재생성하거나 무중복성을 전수 검사합니다:
```bash
# 10x10 퍼즐 데이터셋 생성
node scripts/generator_10x10.js

# 100단계 900문항 무중복 유효성 검증
node scripts/verify_10x10.js
```

### 3. PWA 단일 파일 빌드 (`index.html`)
퍼즐 데이터와 UI 템플릿을 번들링하여 단일 배포본으로 패키징합니다:
```bash
node scripts/build_app.js
```

### 4. 안드로이드 APK 빌드
`android` 디렉토리에서 Gradle을 통해 릴리즈 APK를 생성합니다:
```bash
cd android
./gradlew assembleRelease
# 산출물 위치: android/app/build/outputs/apk/release/app-release-unsigned.apk
```
