# 청춘 7x7 가로세로 낱말 퍼즐 100 🧩

어르신(시니어)을 위한 고대비, 큰 글자, 큼직한 터치 자판, 또렷한 음성 안내(TTS) 및 경쾌한 효과음을 갖춘 7x7 100단계 한국어 가로세로 낱말 퍼즐 PWA 웹앱입니다.

🔗 **서비스 바로가기**: [https://psangho70.github.io/Crossword_puzzle/](https://psangho70.github.io/Crossword_puzzle/)

---

## 🌟 주요 특징 및 기능

1. **시니어 친화적 고대비 UI & 3단 글자 크기 조절**
   - 눈의 피로를 덜어주는 미색 배경(`#FAF8F5`)과 고대비 텍스트
   - **`작게` / `중간` / `크게`** 3단계 글자 크기 즉시 조절 기능
   - 글자 크기를 키워도 7x7 격자판 레이아웃이 밀리거나 깨지지 않는 반응형 비율 고정

2. **총 100단계 스테이지 시스템 (10개 스테이지 × 각 10단계)**
   - 스테이지 1부터 스테이지 10까지 총 100단계 제공
   - 상단 드롭다운으로 원하는 스테이지와 단계로 언제든 자유롭게 이동 가능
   - 완료한 단계에는 `✔` 체크, 올클리어 스테이지에는 `★` 표시 및 전체 진행률 표시

3. **시니어 맞춤형 250개 이상 풍부한 어휘 풀**
   - 추억의 가요/민요 (`소양강처녀`, `동백아가씨`, `고향의봄`, `내나이가어때서`, `남행열차` 등)
   - 속담 및 사자성어 (`금강산도식후경`, `고진감래`, `금상첨화`, `십시일반`, `대기만성` 등)
   - 정겨운 고향 풍경과 전통 문화 (`물레방아`, `원두막`, `장독대`, `가마솥`, `디딜방아` 등)
   - 옛 전통 음식 (`김치찌개`, `된장찌개`, `감자전`, `동치미`, `숭늉`, `인절미` 등)

4. **스마트폰 키보드가 필요 없는 '대형 글자 선택 터치 자판'**
   - 모바일 기본 가상 키보드 없이 10개의 큼직한 한글 음절 버튼(5열×2행, 높이 54px 이상) 터치로 입력
   - 교차로 이미 맞힌 글자는 슬롯에 초록색 잠금 상태로 자동 반영
   - 슬롯이 다 채워지면 자동으로 정답을 판별하여 다음 미해결 문제로 자동 포커스
   - `지우기`, `전체 지우기`, `💡 한 글자 힌트` 지원

5. **음성 안내(TTS), 경쾌한 효과음(Web Audio API), 자동 저장**
   - **🔊 문제 듣기**: 한국어 음성(ko-KR, 속도 0.92)으로 문제를 또렷하게 낭독
   - **효과음**: Web Audio API 오실레이터로 제작된 경쾌한 터치음, 정답 팡파르(도-미-솔-도), 오답음, 단계 클리어 축하 화음
   - **자동 저장**: LocalStorage를 활용해 현재 진행 단계, 클리어 목록, 소리/글자 크기 설정 실시간 저장

6. **완벽한 PWA (오프라인 지원 & 홈 화면 설치)**
   - Cache-First 서비스 워커(`sw.js`) 탑재로 비행기 탑승 모드나 네트워크 없는 오프라인에서도 100% 정상 작동
   - `beforeinstallprompt` 연동으로 상단 원터치 스마트폰 홈 화면 설치 배너 제공
